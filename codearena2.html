Sandbox Security Shield

How CodeArena safely executes untrusted code inside isolated runtime containers.

Seccomp & Syscall Filtering

All code evaluation containers restrict dangerous kernel syscalls like fork bombs, socket creation, and file system writes.

CPU & Execution Time Limits

Submissions are hard-capped at 2.0 seconds execution wall time to eliminate infinite loops and resource hogging.

Strict Cgroup RAM Quotas

Memory usage is constrained to a 256MB limit per evaluation container. Out of memory triggers automatic SIGKILL.
